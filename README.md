# Irina & Jaume

One-page wedding website for September 25th, 2026, at the Cotton House Hotel in Barcelona.

## Local preview

The site is plain HTML, CSS and JavaScript. From the repository folder, run:

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Deployment

Every push to `main` deploys automatically through GitHub Actions:

<https://irinaijaume.cat/>
